# JARED'S EMERALD — project status and build notes

This file tracks the custom ROM-hack work in this repository. It does not claim that features are complete until the code is implemented and the build/test results are checked.

## Target features

- [ ] Custom title screen branding: JARED'S EMERALD
- [ ] Randomized starter choices, generated independently for each new save
- [ ] Randomized wild encounters, without changing an existing save's encounter state
- [ ] Expanded species roster using species already supported by the expansion base
- [ ] Gym Leaders, Elite Four, and Champion use six-Pokémon teams
- [ ] Each of those major trainers has exactly one Legendary and one starter
- [ ] Exactly one genuine shiny Pokémon on each Gym Leader team
- [ ] Level caps based on verified boss-trainer levels
- [ ] Working in-game item/cheat menu, with safe save-data behavior
- [ ] Reproducible build and documented tests

## Build artifact workflow

The GitHub Actions workflow `.github/workflows/jareds-emerald-build.yml` can be started from the repository's **Actions** tab using **JARED'S EMERALD - Build ROM** → **Run workflow**. It also runs when commits are pushed to the `jareds-emerald-dev` branch.

If a build succeeds, the workflow stores `pokeemerald.gba` as an artifact named `jareds-emerald-build` for 14 days. Open the completed workflow run and download the artifact ZIP.

A successful source build is not the same as a completed custom hack. The feature checklist above must be updated only after each feature is implemented and checked.

## Important delivery limitation

This workflow currently builds a ROM artifact, not a BPS/IPS patch. A patch must be generated by comparing a successfully built custom ROM against the matching clean Emerald ROM revision. Do not upload or distribute a copyrighted ROM image. The user should keep their own legally obtained ROM private.
